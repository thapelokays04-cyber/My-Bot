Signal Tracker

No trading and no login. It scans all the strategies on live market data and shows every signal and what it would have made with your lot size.

Press Load signals.

Arrow = entry (green BUY, red SELL) with the strategy tag. Green box = target, red box = stop. Dot = exit: green target, red stop, yellow break-even or trail. Grey line = EMA9, blue = EMA21, orange = EMA200. Shaded blue or purple = fair value gap. Drag the chart to scroll back in time.

Results use closed candles. When one candle touches both stop and target, it counts as a stop. Only the spread you set is charged, so real fees and slippage would lower these numbers. The data covers only the recent candles loaded, which is a small sample.
